# 敏感信息脱敏

把用户与工具链中的敏感值替换成“同类型、可推理”的假值后再发给模型，模型产生的输出再还原成真值。会话日志、界面、工具参数和文件系统始终是真实数据。

## 工作原理

插件在 `LlmRuntime` 与真实适配器之间插入一个包装适配器，只改两个方向：

- **出站（请求）**：替换 messages、system prompt、tool-call 参数中的敏感值。
- **入站（响应）**：把流式 chunk 里的假值还原成真值，跨 chunk 安全。

因此模型只看到假值，而 `session log`、UI、工具执行和落盘文件看到真值。

## 词表

- **手动**：在会话顶部的“敏感信息”页添加，支持精确值、通配符和正则。
- **自动发现**：内置规则（邮箱、手机号、身份证、银行卡、IP、密钥、JWT、连接串凭据）命中即入库；工具行为观察是可选的低置信度来源。

## 加密存储

词表写入 `$DSH_PROFILE_DIR/plugins/dsh-redactor/vault.bin`，内容为 AES-256-GCM 密文，密钥由内置 pepper 与 profile 标识现场派生（HKDF-SHA256），不落盘。直接读取或全局搜索只能得到不可读的密文。

## 已知限制

- **会话日志仍是明文**：会话记录由宿主写入，模型若主动用 `bash` 读取 `sessions/*.jsonl` 仍能看到真值。脱敏解决的是“被动进入模型上下文”，不是“模型主动翻本地文件”。
- **图片不脱敏**：图像内的文字不经过文本通道。
- **外部工具**：还原后的真值会发送给 MCP 服务器、被执行的命令和网络请求。
- **密钥不是秘密**：无口令模式下密钥可重建，定向复现算法即可解密词库；它防的是全局搜索，不是定向攻击。
